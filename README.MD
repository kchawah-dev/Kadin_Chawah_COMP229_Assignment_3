This project is a full-stack Node.js and Express.js backend connected to a MongoDB database, powering a personal portfolio website. It allows users to view pages about me, see my projects and services, and submit a contact form that stores submissions in the database. It also includes full RESTful API endpoints for managing contacts and users.
